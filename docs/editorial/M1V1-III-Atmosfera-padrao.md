CARTÃO
Título: Atmosfera padrão
Pergunta de abertura: Como comparar voos diferentes se o ar muda de um lugar para outro?

1. ESSENCIAL
A atmosfera padrão é um modelo de referência para os cálculos do voo. Ela funciona como uma régua comum, permitindo comparar resultados sob condições definidas. As condições encontradas durante um voo podem diferir desse modelo. [confirmar na referência]

2. ENTENDA
Parágrafo 1: Imagine comparar receitas usando xícaras de tamanhos diferentes. Uma medida comum resolve o problema: a atmosfera padrão estabelece condições de referência para cálculos, ensaios e instrumentos.

4. ATENÇÃO (opcional)
Um valor do modelo não comprova as condições reais da cabine nem determina, isoladamente, a segurança clínica de uma exposição. [confirmar na referência]

6. QUESTÃO DO TESTE
Enunciado: Uma equipe precisa comparar dois ensaios de equipamentos realizados sob condições atmosféricas diferentes. Qual é o papel da atmosfera padrão?
A) Garantir que ambos encontraram exatamente as mesmas condições meteorológicas.
B) Oferecer condições de referência comuns para apresentar e comparar os resultados.
C) Substituir todas as medições feitas durante os ensaios.
D) Determinar automaticamente a aptidão médica das pessoas envolvidas.
Correta: B.
Explicação: O modelo fornece uma referência compartilhada para a comparação dos ensaios. Ele não transforma condições medidas diferentes em condições reais idênticas. [confirmar na referência]
